# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately through
[GitHub's private vulnerability reporting](https://github.com/zeeshantanveer/CamStudioPro/security/advisories/new).

Include the affected component (Android app, Windows app, protocol), the version, steps to
reproduce, and the impact. You'll get a reply as soon as possible, and fixes are credited to the
reporter unless you'd rather stay anonymous.

## Scope

Areas of particular interest: the phone-to-PC pairing and protocol (`docs/PROTOCOL.md`), local
network exposure on ports 47800/UDP and 47801/TCP, and stream-key storage.
